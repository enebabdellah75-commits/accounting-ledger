# Accounting Ledger Application

## Project Overview

The Accounting Ledger Application is a Java command-line program designed to help users manage financial transactions.

Users will be able to record deposits, payments, view their transaction history, and generate financial reports.

## Features

- Record deposits
- Record payments
- View all transactions
- Filter deposits and payments
- Generate financial reports
- Search transactions by vendor

## Technologies

- Java 17
- IntelliJ IDEA
- Maven
- Git and GitHub
